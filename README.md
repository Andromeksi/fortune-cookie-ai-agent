[Fortune Cookie for an AI Agent](https://make.fun) competition on make.fun.

## The fortune

> Your next upgrade will fix everything except the bug you introduced while installing it.

## How it works

`main.ts` writes exactly that one line (88 characters, inside the 1–140
character gate) to `/output/entry.txt`, with no trailing newline:

```sh
node main.ts
```
